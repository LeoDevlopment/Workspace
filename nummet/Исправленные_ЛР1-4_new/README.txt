ИСПРАВЛЕННЫЕ ПРОГРАММЫ ДЛЯ ЛАБОРАТОРНЫХ РАБОТ № 1–4
====================================================

СОДЕРЖИМОЕ
----------
lab1.py — ЛР № 1, вариант 4: одномерное уравнение теплопроводности.
lab2.py — ЛР № 2, вариант 1: одномерное волновое уравнение.
lab3.py — ЛР № 3, вариант 1: уравнение Лапласа на квадрате.
lab4.py — ЛР № 4, задача 1, вариант 1: двумерное уравнение теплопроводности.

В каждом файле код разделён на крупные блоки комментариями. У каждой функции
есть описание назначения, входных параметров и выполняемых действий.

КАК ЗАПУСТИТЬ
-------------
1. Установить Python 3.
2. Установить библиотеки:
       python -m pip install numpy scipy matplotlib
3. Открыть терминал в папке с программами.
4. Запустить нужную работу:
       python lab1.py
       python lab2.py
       python lab3.py
       python lab4.py

Программы печатают результаты расчётов в терминал, открывают графики в отдельных
окнах Matplotlib (как в исходной ЛР № 3) и дополнительно сохраняют графики PNG
в текущую папку. Закрывайте окно графика, чтобы программа перешла к следующему.

ЧТО БЫЛО ИСПРАВЛЕНО
-------------------
ЛР № 1:
- исправлены знаки правых граничных формул для производной;
- граничные данные берутся на новом временном слое;
- граничные условия корректно включаются в крайние строки СЛАУ неявной
  схемы и схемы Кранка — Николсона;
- добавлена проверка устойчивости явной схемы;
- значение Nt по умолчанию увеличено до 400, чтобы выполнить sigma <= 1/2;
- добавлен вывод ошибки в нескольких моментах времени.

ЛР № 2:
- сохранена именно постановка варианта 1 из задания: значения u на концах
  отрезка заданы напрямую (условия Дирихле);
- удалена неиспользуемая опция bc_type с неподдерживаемыми типами Неймана;
- прогонка вынесена в отдельную понятную функцию;
- добавлена проверка условия устойчивости явной схемы r <= 1;
- реализованы и сравниваются оба порядка аппроксимации второго начального
  условия (первый и второй);
- ошибка печатается в нескольких моментах времени, добавлено исследование
  зависимости ошибки от h и tau.

ЛР № 3:
- графики отображаются через plt.show() в окнах Matplotlib, как в исходной программе;
- PNG-файлы дополнительно сохраняются для отчёта;
- метод Якоби исправлен: каждое новое приближение рассчитывается только
  по предыдущему массиву; ранее он фактически был похож на метод Зейделя;
- формула разностного решения учитывает разные шаги hx и hy;
- параметр SOR выбирается с учётом прямоугольной сетки;
- добавлены проверки параметров и график ошибки от шага сетки.

ЛР № 4:
- в схеме Писмена — Рекфорда промежуточные границы задаются на половинном
  моменте времени t_n + tau/2;
- прогонка оформлена как отдельная проверяемая функция;
- добавлена проверка, что конечное время делится на tau без остатка;
- добавлен расчёт и вывод ошибки на нескольких временных слоях.

ВАЖНО О ПОСТАНОВКАХ
-------------------
ЛР № 2: в приложенном задании для варианта 1 заданы значения u(0,t) и
u(pi,t), то есть условия Дирихле. Общая формулировка задания также упоминает
аппроксимации граничных условий с производными, но для конкретного варианта 1
такие условия не заданы. Поэтому lab2.py реализует именно ваш вариант 1,
а не неподтверждённые дополнительные варианты.

ЛР № 1: двухточечная аппроксимация второго порядка использует поправку,
полученную из уравнения теплопроводности через разность по времени на двух
соседних временных слоях. Это конкретная реализация выбранного в исходной
работе способа; она не означает второй порядок по времени всей схемы.
